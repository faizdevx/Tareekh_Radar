# Optional hero artwork

Put an image at `site/assets/hero.webp`, then set `<meta name="cc-hero-image" content="assets/hero.webp">` in `site/index.html`. The image replaces the built-in SVG hero illustration.
It fills the red hero panel (cropped to cover, anchored top-centre); a portrait image around 1000×1200 px works well.

Only use artwork you have the rights to publish: your own, commissioned or licensed for this use,
or openly licensed with attribution. This repository and the deployed site are public.
Avoid imagery that depicts judges or court officials as corrupt; the site's statistics make no such claim.
